Este é um projeto de aulas sobre Pytorch para um curso pós-graduação EAD da Faculdade Infnet.
Para as aulas o ideal é construir exemplos práticos

Dentro do arquivo calendario.csv temos o cronograma das aulas.

 - Cada aula deve ficar em uma pasta separada. 
 - Vamos usar o framework React para criar apresentações quando necessário. No quesito apresentações sempre retorne ao final do processo para conferir slide por slide. No geral devemos ter pouca informação por slide com vários slides. Verifique também se não informação cortada. Prefira sempre imagens e animações interativas ao invés de texto. Você pode criar um arquivo md com as falas do autor para cada slide para suplementar a apresentação. Para a criação seguir o visual do Template de Slides para Aulas.odp que está na pasta raiz. 
 - Mas vamos utilizar Jupyter Notebooks
